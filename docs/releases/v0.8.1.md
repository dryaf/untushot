## UntuShot 0.8.1

The first packaged release of UntuShot: a native Linux screenshot editor built
with Rust, GTK 3 and Cairo.

- Capture regions, full screens or a desktop-selected source, with an optional timer.
- Annotate with arrows, shapes, pen, highlighter, opaque redaction and editable text.
- Copy selected pixels into a new layer, enlarge them, and add borders and shadows.
- Select, rename, reorder, align, duplicate and hide layers; undo up to 100 document steps.
- Save editable `.untushot` projects, export PNGs, copy images and recover sessions.
- Import full-page images from the clipboard and combine multiple screenshots.
- English, German, French and Spanish follow your system language.
- Font-size previews adapt to the installed fonts while keeping their relative scale.
- The English README includes 23 animated feature demonstrations.

### Downloads

**x86-64 / amd64 only.** Built on Ubuntu 22.04 (glibc 2.35).

**Debian package:** Ubuntu 22.04+ and Debian 12+.

```sh
sudo apt install ./untushot_0.8.1_amd64.deb
untushot
```

**AppImage:** bundles GTK and supporting libraries; needs a compatible x86-64
Linux desktop with glibc 2.35 or newer. The bundled Adwaita theme supports
light/dark desktop preferences.

```sh
chmod +x UntuShot-0.8.1-x86_64.AppImage
./UntuShot-0.8.1-x86_64.AppImage
```

If FUSE is unavailable:

```sh
APPIMAGE_EXTRACT_AND_RUN=1 ./UntuShot-0.8.1-x86_64.AppImage
```

Check the downloads with `sha256sum -c SHA256SUMS` after downloading both packages
and `build-info.json`. Build information records the source commit and packaging
tool checksums. Checksums provide integrity checking; this release is not signed.

Desktop capture needs the compositor's screenshot portal or `grim` on a supported
Wayland compositor. Tray icons need desktop AppIndicator support. The packages
install an application launcher; they do not modify your global shortcut or
start an autostart process. These can be configured in your desktop settings.

Validated with optimized application/security tests and isolated GTK workflows.
Both packaged editors were checked on Ubuntu 22.04, Ubuntu 26.04 and Debian 12;
Debian package installation and removal were also checked in a clean container. Real portal
permission dialogs, tray integration and mixed-DPI monitor capture remain
dependent on your desktop environment.
